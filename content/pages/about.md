## 为什么写

写作是一种延迟满足的思考。很多以为自己懂了的东西，落到纸面上就会露出缝隙：定义没有说清，假设被悄悄换掉，结论其实只在很窄的条件下成立。

这个站点是我的外部记忆，也是一次公开的练习。它不追求覆盖多少主题，只记录那些值得反复理解的问题——某个结论究竟依赖什么，某个方法为什么有效，以及它在什么时候会失效。

目前它还是空的。框架、排版与知识地图已经就位，内容会慢慢填进来。

## 关心什么

大致在四个方向的交界处：

- **概率与信息**：不确定性如何被度量，为什么高维空间里的直觉常常是错的；
- **学习理论**：容量、泛化与在线错误之间，哪些联系是本质的；
- **优化**：一个方法到底在优化什么，噪声与步长如何改变它的行为；
- **智能系统**：从强化学习到表示学习，机制层面的解释而不是排行榜。

我不太相信“只要规模足够大，一切都会自然出现”这类叙事。规模当然重要，但它解释不了结构。

## 怎么写

每一篇尽量回答三个问题：

1. **结构**——结论依赖哪些定义与假设？哪一步是真正关键的？
2. **机制**——方法为什么有效？不变量、信息流与计算过程是什么？
3. **边界**——它在什么条件下失效？有没有反例或实验？

推导优先于结论，具体例子优先于术语堆叠。遇到不确定的地方，我会直接标出来，而不是用流畅的句子掩盖它。

## Colophon

这个站点没有使用现成的博客框架。它由一段几百行的 Node 静态生成器编译：

- 文章用 Markdown 写作，公式由 KaTeX 在构建时渲染为静态 HTML；
- 页面是手写的 HTML 与 CSS，客户端 JavaScript 只负责搜索、主题、目录与知识地图；
- 字体自托管，不依赖第三方 CDN；
- 托管在 GitHub Pages，每次推送自动构建部署。

完整源码与部署说明在仓库的 `README.md` 里。如果你想把它改成自己的站点，主要只需要编辑 `site.config.mjs`。

## 边界

这里的文字是学习过程中的整理，不是权威综述。错误一定存在，观点也会变化。如果你发现推导有问题，或者有更好的解释，欢迎写信告诉我。

> 把复杂的问题想清楚一点，就已经很不容易了。
